Software y nuevas tecnologías · qué estudiar

Es un mundo corto. Aprende para qué sirve cada herramienta y reconoce las aplicaciones habituales en producción y difusión cultural.

Antes de leer

La pregunta útil ante cada herramienta es: qué problema ayuda a resolver. Un programa de hojas de cálculo ordena importes y fechas; una base de datos organiza registros; una herramienta de escena prepara señales para la función.

Ejemplo: para controlar el presupuesto y el calendario de un ciclo cultural, una hoja de cálculo permite reunir gastos, fechas y responsables. Para lanzar de forma ordenada música y vídeo durante una representación, se usa software específico de escena.

Aprende usos y diferencias generales; la ficha no exige dominar menús, programación ni configuraciones avanzadas.

Ofimática y gestión

  • Word: documentos y plantillas.
  • Excel: presupuestos, tablas, cronogramas y seguimiento.
  • Access: bases de datos sencillas.
  • PDF (Portable Document Format; formato de documento portátil): formato para intercambiar, firmar, revisar y archivar documentos conservando su presentación.

Software aplicado a escena

QLab y herramientas equivalentes permiten organizar y lanzar señales o pies (cues) de audio, vídeo o control escénico. Cada señal se prepara para activarse en un momento determinado. Lo importante es su finalidad, no memorizar menús o atajos.

Nuevas tecnologías culturales

Repasa digitalización de fondos, plataformas de difusión y venta, streaming (emisión de audio o vídeo por internet), realidad aumentada, inteligencia artificial (IA) aplicada a catalogación o accesibilidad y herramientas de gestión de públicos.

Ejemplo: una institución puede digitalizar un archivo para preservarlo, publicar parte de sus fondos para ampliar el acceso y usar IA como apoyo para describir materiales; cada uso plantea objetivos y límites distintos.

Hasta dónde

Nociones generales y usos. No estudies manuales completos, programación ni configuraciones técnicas avanzadas.

Resumen para fijarlo

  • Word crea documentos; Excel organiza cálculos y seguimiento; Access guarda registros estructurados.
  • PDF facilita compartir documentos con una presentación estable.
  • QLab organiza señales de escena que se activan en el momento acordado.
  • Digitalización, difusión, realidad aumentada e IA son usos distintos de tecnología cultural.

Términos clave

Base de datos
Conjunto ordenado de registros que pueden consultarse y actualizarse.
Pie o señal (cue)
Indicación preparada para activar un sonido, vídeo o acción de escena.
Digitalización
Conversión de materiales o procesos analógicos en formato digital; no equivale por sí sola a difundirlos.
Inteligencia artificial (IA)
Herramientas que realizan tareas como clasificar o generar contenido mediante sistemas computacionales.

Posibles trampas del test

  • Confundir hoja de cálculo con base de datos.
  • Confundir conservar un archivo digital con publicarlo en línea.
  • Tratar QLab como una herramienta de edición de vídeo en lugar de un sistema para preparar y lanzar señales de escena.
  • Atribuir a la IA garantías de exactitud o accesibilidad automática.
